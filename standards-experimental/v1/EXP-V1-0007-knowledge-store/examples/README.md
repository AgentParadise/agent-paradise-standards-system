# Knowledge Store Examples

`minimal/knowledge-fact.json` is one fact that satisfies principles P1 and
P2: a random item id, a compartment id, a content reference and a provenance
reference. Nothing in it is derived from the owner's text. The provenance
blob (not shown) holds the source path and title behind a random nonce.

It is an illustration of the shape, not a schema. This experiment defines no
wire format.
