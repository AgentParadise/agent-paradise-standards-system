See [README.md](README.md) for the index and overview of this directory.

Per standard docs live inside each standard package under
`standards/v1/<ID>/docs/` or
`standards-experimental/v1/<ID>/docs/`, not here. This directory is
for material that does not belong to any single standard, such as
design proposals informing in flight standards work.
