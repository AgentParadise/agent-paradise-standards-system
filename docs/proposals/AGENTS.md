name: "Design proposals (agent context)"
description: "Short pre decision design notes; the recommendation is the operator's call, not the spec's"
---

See [README.md](README.md) for the index and overview of this directory.

Each file here is a short proposal for in flight standards work. The
proposal lists two or three concrete options, names a recommendation,
and the operator picks the final shape. The picked option lands as
normative spec text in the relevant standard's `docs/`. The proposal
file stays in this directory after the decision so the reasoning is
part of the audit trail.
