# Design proposals

This directory holds short design proposals for in flight standards
work. Each proposal lays out two or three concrete options, names a
recommendation, and explains why. Proposals are informative; the
operator picks the final shape, which lands as spec text in the
relevant standard's `docs/`.

A proposal can be retired once the operator decides; the file stays
so the reasoning is part of the audit trail.
