# APSS repository docs root

This `docs/` directory holds cross cutting documentation for the
Agent Paradise Standards System repository itself. Per standard
documentation lives inside each standard package under
`standards/v1/<ID>/docs/` or
`standards-experimental/v1/<ID>/docs/`; this directory exists for
material that does not belong to any single standard.

The repository dogfoods the EXP-V1-0004 documentation standard, so
every subdirectory here carries a `README.md` with a generated
`## Index` table and a pair of context files (`AGENTS.md` and a
`CLAUDE.md` symlink) per the parent spec.

## Subdirectories

- [`proposals/`](proposals/README.md) - design proposals informing
  in flight standards work.
